# GeneratePassword

**GeneratePassword** es una herramienta web para generar contraseñas personalizadas de forma rápida y sencilla.

La aplicación permite definir las características de la contraseña según las necesidades del usuario, seleccionando la cantidad de caracteres, los tipos de caracteres que desea incluir y el formato requerido.

## Características

* Generación de contraseñas aleatorias.
* Definición de la longitud de la contraseña.
* Selección de los tipos de caracteres.
* Personalización del formato de la contraseña.
* Generación rápida de nuevas contraseñas.
* Interfaz sencilla y enfocada en una única función.
* No requiere procesos complejos para utilizarla.

## Personalización

El usuario puede establecer las características que debe cumplir la contraseña, incluyendo:

* Cantidad de caracteres.
* Letras.
* Números.
* Caracteres especiales.
* Combinaciones de diferentes tipos de caracteres.
* Formato deseado.

Esto permite generar contraseñas adaptadas a diferentes requisitos de seguridad o políticas de sistemas.

## Objetivo

El objetivo de **GeneratePassword** es proporcionar una herramienta sencilla para crear contraseñas sin tener que construirlas manualmente.

La aplicación busca facilitar la generación de combinaciones de caracteres que puedan utilizarse en cuentas, aplicaciones, sistemas o cualquier otro escenario donde sea necesario crear una nueva contraseña.
